# countdown-test

صفحة عد تنازلي بسيطة بالعربية (RTL) حتى ١٠ يناير ٢٠٢٧ بتوقيت القاهرة.

A minimal dark Arabic (RTL) countdown page to January 10, 2027, Cairo time.

## المحتويات

- `index.html` — الصفحة كاملة: HTML وCSS وJavaScript في ملف واحد، بدون أي مكتبات خارجية.

## التشغيل

افتح `index.html` في أي متصفح. العد التنازلي يحدّث كل ثانية ويعرض الأيام والساعات والدقائق والثواني المتبقية.
